# Security Policy

## Supported versions

MailAgent is currently pre-1.0. Security fixes are applied to the latest
released minor version only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for `Fumikua/mailagent`. Include affected
versions, impact, reproduction steps, and any suggested mitigation.

Never include production email, credentials, API keys, customer identifiers,
or private vertical assets in a report. Replace them with synthetic examples.

We aim to acknowledge a complete report within five business days. Disclosure
timing will be coordinated after a fix and release path are available.
